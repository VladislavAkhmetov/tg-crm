# Спецификация интерфейса Creative UGC CRM

## 1. Концепция и рабочая единица
Базовая рабочая единица системы — **артикул товара (SKU)**. Каждая задача проходит 6 этапов:
1. `available` — свободно (в пуле, доступно любому дизайнеру).
2. `in_progress` — в работе (закреплено за дизайнером).
3. `internal_review` — внутренняя проверка (сдана внутренняя Figma, ждет ревью арт-лида).
4. `client_review` — согласование заказчиком (передана во внешнюю Figma заказчика).
5. `export_ready` — готово к экспорту (согласовано клиентом, требуется загрузка финалов).
6. `completed` — завершено (финальные архивы загружены на облачный диск).

---

## 2. Навигация и фильтрация

* **Постоянные вкладки:**
  - **Все** — все активные задачи по выбранным пулам/статусам.
  - **Мои** — все активные задачи текущего пользователя (в работе, на проверке, у заказчика, на экспорте).
  - **Свободные** — задачи, доступные для взятия в работу (фильтр этапа автоматически скрывается).
* **Модальные шторки фильтров:**
  - Фильтры пулов и этапов открываются в нижней шторке (на смартфонах) или всплывающем модальном окне (на десктопе).
  - Счётчики в строках фильтров динамически отражают количество задач с учетом текущего поиска и роли.
* **Поиск:**
  - Поддерживает мгновенный поиск по номеру артикула (SKU), названию пула, имени или username исполнителя.

## 3. Карточка задачи и модальные действия

* **Карточка в ленте:**
  - Артикул — кликабельный моноширинный заголовок с мгновенным копированием в буфер обмена.
  - Быстрые ссылки: `📁 Фото` (прямая ссылка на исходники в облаке), `🎨 Figma` (при наличии).
  - Контекстная главная кнопка: зависит от текущего этапа задачи и прав пользователя («Взять в работу», «Сдать макет», «На проверку клиенту», «Финалы на диск» и др.).
  - Блокировка повторных кликов и индикация загрузки при мутациях.
* **Детальная карточка (Task Detail Sheet):**
  - Полная история комментариев и правок (активные правки выделяются предупреждающим стилем).
  - Управление количеством слайдов/изображений (`images_count`).
  - Привязка и переход к задаче в Битрикс24 (`bitrix_url`).
  - Дополнительные действия: «Вернуть в свободные» (доступно исполнителю и админу), переназначение дизайнера (для лида), архивация.

## 4. Визуальная система (Design Tokens)

* **Цветовая палитра (Dark Slate & Lime):**
  - Фоновая подложка: `#0A0B0D`
  - Поверхности карточек: `#13161A` / `#16191E`
  - Границы и разделители: `#1F242C` / `#282D36`
  - Основной акцентный цвет (CTA): лаймовый `#C8EE94` (кнопки, активные фильтры, бейджи)
  - Цвета статусов:
    - Свободно: приглушенный серый `#94A3B8`
    - В работе: янтарный `#FBBF24`
    - Внутренняя ОС: лазурный `#38BDF8`
    - ОС Заказчика: фиолетовый `#C084FC`
    - На экспорт: оранжевый `#FB923C`
    - Готово: изумрудный `#4ADE80`
    - Правки / Замечания: мягкий красный `#F87171`
* **Типографика:**
  - Полностью локальные самохостящиеся шрифты (без внешних CDN):
    - **Onest** (400, 500, 600, 700) — заголовки, интерфейсный текст, кнопки, описания.
    - **JetBrains Mono** (500, 600) — артикулы SKU, счетчики задач, таймстемпы.
* **Адаптивность и Telegram WebApp Integration:**
  - Учет безопасных зон Telegram (`safeAreaInset`, `contentSafeAreaInset`).
  - Интеграция с нативной кнопкой BackButton и Haptic Feedback Telegram.
  - Полнофункциональный отдельный интерфейс для широких экранов: `static/desktop.html`.

## 5. Тестирование и валидация

1. **Модульные тесты интерфейса (Node.js Test Runner):**
   ```bash
   node --test tests/frontend.test.cjs
   ```
   Проверяет фильтрацию, права доступа ролей, видимость действий, экранирование пользовательского контента, логику возврата в пул и группировку.

2. **Интеграционные тесты API и базы данных (Python Unittest):**
   ```bash
   python -m unittest discover -s tests -p "test_*.py"
   ```
   Проверяет эндпоинты FastAPI, жизненный цикл задач, назначение исполнителей, экспорт в Excel/Google Sheets и транзакции SQLite.

3. **Изолированный локальный просмотр UI:**
   ```bash
   preview.bat
   ```
   Запускает сервер на порту 8001 с тестовым набором данных во временной базе данных в памяти.
