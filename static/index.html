Формат выгрузки
Подключение Google Таблицы (1 мин):
  1. В вашей Google Таблице откройте меню: Расширения ➔ Apps Script.
  2. Удалите стандартный текст (function myFunction), вставьте скопированный код и нажмите 💾 Сохранить (Ctrl+S).
  3. Вверху нажмите синюю кнопку «Начать развертывание» ➔ «Новое развертывание».
  4. Выберите тип: шестеренка ⚙️ ➔ «Веб-приложение».
  5. В поле «У кого есть доступ» обязательно укажите: «Все» (Anyone), Запуск от: «Я».
  6. Нажмите «Развернуть», разрешите доступ к аккаунту, скопируйте URL веб-приложения (заканчивается на /exec) и вставьте в поле выше.
